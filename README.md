# 👟 SneakerClub App 2.0

**Mô tả:** Dự án này tập trung vào việc tái cơ cấu ứng dụng để nghiên cứu và phân tích thêm về **Java Swing**.

## 🛠 Công nghệ & Công cụ
*   **Ngôn ngữ:** Java (94.9%), TSQL (5.1%).
*   **Framework:** Java Swing.
*   **Quản lý dự án:** Maven (`pom.xml`).
*   **Thư viện:** Apache POI (xử lý file Office).
*   **IDE:** Tối ưu cho NetBeans (`nbactions.xml`).

## 📂 Cấu trúc dự án
*   `src/main`: Mã nguồn chính của ứng dụng.
*   `SQL`: Script khởi tạo và quản lý cơ sở dữ liệu.
*   `docx`: Tài liệu báo cáo và phân tích.
*   `Libaries`: Thư viện phụ trợ.

## 🚀 Cài đặt nhanh
1.  **Clone:** `git clone https://github.com/MarcusTr98/SneakerClub_App.git`
2.  **Database:** Chạy script trong thư mục `SQL`.
3.  **Run:** Mở dự án bằng NetBeans/IntelliJ và chạy file main.
